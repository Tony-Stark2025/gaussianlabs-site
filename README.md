# Gaussian Labs — Piton Website

Static marketing and documentation landing page for **[Gaussian Labs](https://www.gaussianlabs.dev)** and **[Piton](https://github.com/Tony-Stark2025/piton)** (`v0.4.2`, MIT) — the deterministic split-hash lockfile, coding-agent hook RCE linter, shadow-to-enforce `CEL`/`Cedar` replay tool, and Go Envoy v3 `ext_proc` sidecar for Model Context Protocol (MCP) servers and AI coding agents.

## Deployment

Deployed directly as a static site on Vercel (`https://www.gaussianlabs.dev`) with strict security headers configured in [`vercel.json`](./vercel.json).
