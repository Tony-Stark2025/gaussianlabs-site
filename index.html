Core Architecture

Built for Post-2026 Application & Agentic Threats

Static linters miss business logic and flood developers with dead-code CVEs. Prometheus combines live exploitation with compiler-checked repair.

1. Zero-FP Verification

3-Tier PoV & Semantic Triage

Tier-A Verified PoVs (BOLA/BFLA, TOCTOU race conditions, OOB SSRF callbacks, negative-quantity checkout bugs) block PRs with runnable curl & pytest proofs. Non-oracle sinks (timing leaks, weak crypto, ReDoS) route to Tier-B Triage instead of being silently dropped.

2. Dual-Pass CEGIS

Compiler-Verified Auto-Patching

Synthesizes framework-idiomatic patches, runs native compilers (py_compile, node --check) in secret-stripped worktrees, blocks leaked API/GitHub tokens, and proves Attacker gets 403/404 while Victim retains 200 OK.

3. Coding-Agent Firewall

GitSpawn, Plugin4Shell & Package Firewall

Detects malicious .git/config directives (sshCommand, hooksPath, script fsmonitor), poisoned .cursor/mcp.json / .claude/settings.json configs, and malicious npm lifecycle hooks before an AI coding agent opens the repo.

4. Continuous Immunology

Route-to-CVE Call-Graph Bridge

Queries OSV.dev and live threat feeds, strips ~85% of unreachable dead-code CVE noise via AST call-graph tracing, and maps vulnerable packages straight to the exposed HTTP routes (POST /api/...) that invoke them.
