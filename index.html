01 / Verification Oracle

Never block a merge on a guess.

Static scanners flood pull requests with theoretical warnings that developers learn to ignore. Prometheus separates findings into strict evidence tiers: only mathematically proven runtime exploits block a PR, while subtle logic and crypto risks route cleanly to Tier-B triage.

  • Proves multi-tenant BOLA/BFLA, TOCTOU races, and OOB SSRF with runnable curl and pytest harnesses.
  • Compiles synthesized patches in secret-stripped worktrees and verifies no tokens leak into diffs.
  • Dual-Pass CEGIS confirms the attacker now receives 403 while the legitimate tenant keeps 200 OK.

02 / Continuous Immunology

Fix the 3 CVEs exposed to the internet, not 400 in dead code.

Lockfile scanners treat every dependency as an emergency. Prometheus parses your codebase into an Abstract Syntax Tree, traces real import and call sites, and links OSV.dev advisories directly to the public HTTP routes that execute them.

  • Every scan reports exact coverage: files scanned, routes discovered, and dependencies checked.
  • Generates clean manifest upgrade diffs for reachable packages without breaking unrelated lockfile pins.
03 / Agentic Supply-Chain Defense

Built for repositories opened by AI coding agents.

Modern repositories aren't just read by compilers—they are executed by Cursor, Claude Code, and CI agents. Prometheus audits the configuration surfaces attackers use to hijack autonomous developer workflows.

GitSpawn Protection

Flags malicious core.sshCommand, core.hooksPath, and script-executing fsmonitor directives that trigger silent shell execution on clone or pull.
