01 / Split-Hash Pinning

Stop MCP rug pulls without breaking internal deploys.

Naive single-hash pinning breaks CI every time an internal team edits a tool docstring. Piton splits every MCP tool pin into a machine contract hash (structural_sha256) and a prose hash (description_sha256).

  • structural_sha256 hard-blocks silent inputSchema parameter injection across every server.
  • description_sha256 hard-blocks third-party MCP rug pulls while warning on internal docstring edits unless poisoning lint triggers.
  • Catches cross-server tool shadowing before an attacker can hijack a privileged tool name.
